# Required Parameter

- รูปแบบกล่อง
- ขนาดของกล่อง หรือ dieline
- กระดาษ , ความหนากระดาษ gram
- จำนวนสีพิมพ์ ด้านนอก/ด้านใน CMYK + สีพิเศษอื่นๆ
- จำนวนชิ้นงานที่ต้องการ

# Fixed Process : Process ตายตัว

- Die-cutting : การทำให้เกิดรอยปรุ-ประ เพื่อให้สามารถแกะชิ้นงานออกจากกระดาษได้
- Chip แกะ : การแกะชิ้นงานออกจากกระดาษ เพื่อนำไป Packing หรือ ขึ้นรูปต่อไป
- Assembly ปะติดกาวลิ้นข้าง : ทำเพื่อพับขึ้นรูป
- Inspection : การตรวจสอบงานผลิตด้วย QC

# Optional Process : ตัวเลือกเพิ่มเติม

- Special Ink สีพิเศษ : ระบุ Pantone เพื่อให้ได้สีที่แม่นยำขึ้น
- Coating เคลือบ : เคลือบชิ้นงานด้วยสี / วัสดุต่างๆ เพื่อวัตถุประสงค์ที่แตกต่างกันออกไป มีทั้งการเคลือบ 1 ด้าน และ 2 ด้าน (ด้านนอก/ด้านใน)
- Foil stamp ปั้มฟอยล์ , เคฟอยล์ : คือการปั้มฟอยล์ด้วยแม่พิมพ์ และฟอยล์สีต่างๆลงบนผิววัสดุ เพื่อให้เกิดลวดลาย โลโก้ หรือข้อความที่มันเงา วาวแบบโลหะ เพิ่มความหรูหรา
- Emboss / Deboss ปั้มนูน-จม : ใช้ Block เพื่อกดให้เกิดความนูน/จมของผิววัสดุ เพิ่มมิติให้กับชิ้นงาน มักจะทำร่วมกับการเคฟอยล์
- Digital-die-cut : การ Die-cut ด้วยเครื่องใช้ใบมีด หรือเลเซอร์ในการตัด ไม่ต้องใช้ block
- Corrugated Glue : การทากาวประกอบกระดาษปกติ กับลูกฟูก เฉพาะรูปแบบกล่องที่เลือกประกบลูกฟูก

# Coating Type ประเภทการเคลือบ :

- การเคลือบ คือการเคลือบผิววัสดุด้วยสี , ฟิล์ม , พลาสติก ในรูปแบบต่างๆตามจุดประสงค์ของการใช้งาน เช่น เคลือบกันน้ำสำหรับใส่อาหาร เป็นต้น
- การเคลือบจะต้องเลือก 2 ส่วนหลักๆ คือ 1. เงาหรือด้าน , 2. รูปแบบ หรือเทคนิคการเคลือบ เช่น Spot UV , UV , Waterbase , OPP เป็นต้น
- การเคลือบ Spot UV เป็นการเคลือบแบบกำหนดจุด หากเลือก Process นี้จะต้องระบุขนาดของจุดที่ต้องการเคลือบในหน่วยนิ้ว(inch) กว้าง x ยาว
- การเคลือบ Blister Pack เป้นการเคลือบด้วยพลาสติกใสขึ้นรูป เช่น แผงยา แปรงสีฟัน เพื่อให้เห็นสินค้าชัดเจน ด้วยวัสดุพลาสติก PVC , PET เป็นต้น (ระบุ)
- พลาสติก PVC เหมาะกับการใช้งานทั่วไป ทนทาน ยืดหยุ่นสูง
- พลาสติก PET เหมาะกับการใช้งานกับของกินได้
- การเคลือบในรูปแบบอื่นๆ จะเป็นการเคลือบชิ้นงานทั้งแผ่นโดยใช้ Layout size ในการเคลือบ (เคลือบทั้งแผ่นพิมพ์)
- การเคลือบจะต้องระบุจำนวนหน้าที่ต้องการเคลือบ 1 หมายถึง ด้านนอก , 2 หมายถึง เคลือบทั้งด้านนอกและด้านในของกล่อง

# Foil stamp :

- การเคฟอยล์ หรือ สแตมป์ฟอย จะช่วยเพิ่มความหรูหรา ให้กับชิ้นงาน เหมาะจะใช้กับพวกโลโก้ ตัวหนังสือ หรือรายละเอียดอื่นๆที่ต้องการเน้นเพื่อเพิ่มความหรูหรา มูลค่า
- การเลือก Process นี้จะต้องระบุขนาดของพื้นที่เป็นหน่วยนิ้ว (inch) ที่ต้องการสแตมป์ อาจกำหนดมากกว่า 1 จุดได้
- สามารถกำหนดสีที่ต้องการได้ เช่น ทองด้าน , ทองเงา , เงิน , โรสโกลด์ , น้ำเงิน , แดง เป็นต้น
- การเลือก Process นี้จะมีการคิดราคาค่า Block และ ค่าแรงร่วมด้วย

# Emboss / Deboss :

- การปั้มนูน หรือ จม จะต้องกำหนดขนาดพื้นที่ที่ต้องการปั้มเป็นหน่วยนิ้ว (inch) อาจกำหนดมากกว่า 1 จุดได้
- แต่ละจุดสามารถกำหนดความนูน / ลึก ได้ 2 ขนาดคือ 1.25 mm และ 1.65 mm
- การเลือก Process นี้จะมีการคิดราคาค่า Block และ ค่าแรงร่วมด้วย

# Machine :

- ประเภทพิมพ์ Offset : จะมีเครื่องพิมพ์ที่ใช้งานได้คือเครื่อง L444SP - Cut 1 , L440 - Cut 2 , LS1029 - Cut 3 โดยขนาดของกระดาษที่เครื่องรับได้เรียงจากใหญ่->เล็ก คือ 1->3
- โดยส่วนมากหากรูปแบบงาน ไม่ประกบลูกฟูก , ประกอบลูกฟูก จะใช้ Cut 2 เป็นหลัก
- ประเภทพิมพ์ Jet Press : เหมาะกับงานรูปแบบเดียวกับ Offset แต่จะต่างกันที่หากผลิตเป็นจำนวนน้อยจะราคาถูกกว่า เนื่องจากไม่มี Fixed Cost เรื่องเพลท และ setup เครื่อง โดยมากจะเป็นงานที่ต้องการงานพิมพ์คุณภาพสูงที่สุด
- ประเภทพิมพ์ Flexo : จะเป็นเครื่องทำกล่องลูกฟูกโดยเฉพาะ โดยมี 2 ขนาดคือ max size 15.75x21" และ 57x94.4" จะใช้กับงาน เฉพาะลูกฟูก
- ประเภทพิมพ์ Konica : มักจะใช้กับงานสติ๊กเกอร์ หรืองานผลิตจำนวนน้อยๆ ที่ไม่เน้นความละเอียด

# คำศัพท์ที่เกี่ยวข้องกับการวาง Layout และคำนวณกระดาษ :

- เกรนกระดาษ : แนวเส้นใยของกระดาษที่เรียงต่อกัน เมื่อซื้อกระดาษมาผลิตชิ้นงาน มักจะซื้อเป็นม้วนหลาย tons เกรนกระดาษจะขนานด้านยาวของกระดาษเสมอ (เรียงต่อกันตามแนวของม้วนกระดาษ) กล่าวคือ "ตรงข้ามกับหน้าม้วน"
- หน้าม้วน : ด้านกว้างของหน้าม้วนกระดาษ
- เกรนชิ้นงาน : การระบุแนวของเกรนกระดาษที่เหมาะสมกับชิ้นงาน หรือประเภทกล่องนั้นๆ (ส่งผลต่อความแข็งแรงของชิ้นงาน หรือกล่อง)
- ถูกเกรน : การวางชิ้นงานบนกระดาษให้เกรนของชิ้นงาน และเกรนกระดาษสัมพันธ์กัน(ไปในแนวเดียวกัน) จะช่วยให้ชิ้นงานมีความแข็งแรง
- ผิดเกรน : การวางชิ้นงานบนกระดาษให้เกรนของชิ้นงาน ตรงข้ามกับเกรนกระดาษ ส่งผลให้ชิ้นงานมีความแข็งแรงน้อยลง (กรณีนี้หากชิ้นงานไม่ต้องการความแข็งแรงมาก จะถูกเลือกใช้เพื่อให้สามารถวางเลย์เอาท์ชิ้นงานได้จำนวนมากขึ้น หรือเพื่อให้แนวเส้นพับของชิ้นงานสามารถพับได้ง่ายขึ้น)
- Cut off : ด้านความยาวของกระดาษที่ตัดออกมาเป็นแผ่น
- Paper Size : ขนาดกระดาษที่ใช้ในการพิมพ์
- Source Paper Size : ขนาดกระดาษแผ่นใหญ่ที่นำมาตัดเจียรให้ได้ Paper Size
- Open Size : ขนาดของชิ้นงานในรูปแบบกางออก (วางแผ่) และวัดที่กรอบด้านนอกจะได้ขนาด กว้าง x ยาว
- Fold Size : ขนาดพับเข้าของชิ้นงานเพื่อขึ้นรูป
- Finish Size : ขนาดสำเร็จหลังขึ้นรูป โดยทั่วไปจะเท่ากับ Fold Size จะเป็นขนาด กว้าง x ยาว x สูง
- Packing Size : ขนาดของชิ้นงานที่ใช้สำหรับนำไป Packing โดยมากมักจะเท่ากับ Open Size (ไม่ต้องขึ้นรูปกล่อง) จะเป็นขนาด กว้าง x ยาว x หนา (หนาจากกระดาษ)
- Qty : จำนวนชิ้นงาน
- Ups : จำนวนชิ้นที่งานที่วางลงบนกระดาษ 1 แผ่นเล็กได้ (วาง Layout)
- After Ups : Roundup( Qty / Ups ) จำนวนกระดาษที่ต้องใช้เพื่อผลิตชิ้นงานให้ครบตามจำนวนที่ต้องการ
- Waste : จำนวนเผื่อเสียกระดาษ เมื่อพิมพ์งานลงบนกระดาษ และผ่าน Process ต่างๆจะต้องมีการเผื่องานเสีย พิมพ์เสีย โดยมีเรทตาม Database
- After Waste : Roundup( After Ups + Waste ) จำนวนกระดาษแผ่นเล็กที่ต้องใช้รวมเผื่อเสีย
- Sig : จำนวนยกพิมพ์ ชิ้นงาน 1 ชิ้นต้องพิมพ์ลงบนกระดาษที่แผ่นถึงจะผลิตชิ้นงานได้ 1 ชิ้น ( Packaging จะต้องพิมพ์ลงบนกระดาษให้ได้อย่างอย่างแน่นอน 1 ชิ้น : 1 แผ่น ดังนั้น sig = 1 เสมอ)
- Paper Print : After Waste \* Sig คือจำนวนกระดาษที่ต้องใช้เพื่อทำให้ได้ชิ้นงานครบตามจำนวนครั้งที่พิมพ์
- Split : จำนวนการแบ่งกระดาษแผ่นใหญ่ (Source paper size) เป็นกระดาษแผ่นเล็กสำหรับพิมพ์ เช่น แผ่นใหญ่ 31x43นิ้ว แบ่งเป็น 16.5x21.5นิ้ว ได้ split = 4 คือ (ด้าน/ด้าน \* ด้าน/ด้าน)
- Paper Qty : Roundup(Paper Print / Split) คือจำนวนกระดาษแผ่นใหญ่ที่ต้องใช้ทั้งหมด
- Paper Net : Roundup Paper Qty -> จำนวนเต็ม 100 เพื่อสั่งซื้อ
- Tons : น้ำหนักรวมของกระดาษที่ต้องใช้ทั้งหมด โดยคำนวณจาก (( Paper Net _ Gram / 1550000 _ ขนาดกระดาษ(นิ้ว)ด้านกว้าง \* ขนาดกระดาษ(นิ้ว)ด้านยาว) / 1000)

# Layout การวางเลย์เอาท์เพื่อพิมพ์-ผลิตชิ้นงาน :

- การวางเลย์เอาท์จะใช้หน่วยขนาดเป็น มิลลิเมตร และ นิ้ว เป็นหลัก
- การวางเลย์เอาท์ คือ การนำชิ้นงานขนาดกางออก (Open size) + ระยะเผื่อ bleed 3 mm รอบด้าน มาวางลงบนกระดาษที่ใช้พิมพ์เพื่อหาจำนวนชิ้นที่วางได้ในกระดาษไซส์นั้นๆ
- การเสียเศษกระดาษ คือ การนำชิ้นงานมาวางบนกระดาษ และเหลือเศษกระดาษที่ไม่สามารถวางชิ้นงานได้อีก
- การวางเลย์เอาท์ที่ดีคือการเลือกขนาดกระดาษให้เหมาะสมกับจำนวนชิ้นงานที่วางได้โดยเสียเศษพื้นที่กระดาษน้อยที่สุด
- Print size คือ ขนาดพื้นที่พิมพ์ หรือ ขนาดกรอบรอบนอกของชิ้นงานทั้งหมดที่วางลงบนกระดาษแล้วและตีเป็นกรอบสี่เหลี่ยมจะได้ขนาด กว้าง x ยาว โดยมีชิ้นงานอยู่ข้างใน 1:n ชิ้น
- Layout size คือ ขนาดพื้นที่พิมพ์ + ระยะเผื่อ ( gripper , color bar , paper edge )
- การวางเลย์เอาท์แบบปกติ เป็นการวางในทิศทางเดียวกันทั้งหมดตามแนวเกรนกระดาษ
- การวางแบบเหลื่อมกัน เป็นการวางโดยนำส่วนที่ยื่นออกมาจากแต่ละกล่อง เสียบเข้ากับส่วนเว้าของอีกชิ้นหนึ่ง ตามขนาดของชิ้นงาน
- การวางเลย์เอาท์จะต้องรู้ขนาด Min , Max size ของเครื่องพิมพ์ที่จะนำกระดาษไปพิมพ์ก่อน จึงจะสามารถกำหนด หรือเลือกขนาดกระดาษที่ใช้วางเลย์เอาท์ได้

# Printing การพิมพ์ :

- ระบบ Offset : เหมาะกับงานที่ต้องการผลิตจำนวนมากๆเพราะมี Fixed Cost สูงในการเริ่มต้น, ต้องใช้แม่พิมพ์ (Plate) , สีคมชัด สม่ำเสมอ
- ระบบ Jet Press : เหมาะกับงานพิมพ์คุณภาพสูง , พิมพ์ตรงจากไฟล์ดิจิทัล ใช้หมึก และกระดาษเฉพาะ , ไม่ต้องมีเพลท , ต้นทุนสูงกว่า Offset เมื่อต้องพิมพ์ในปริมาณมากๆ
- ระบบ Konica : พิมพ์ตรงจากไฟล์ดิจิทัล ใช้หมึกแบบผง, รวดเร็ว แต่ความละเอียดต่ำกว่า Offset และ Konica และมีข้อจำกัดเรื่องความหนาของกระดาษ
- เครื่อง Flexo : เหมาะกับทำกล่องลูกฟูก และงานพิมพ์ที่ไม่เน้นความละเอียด , จำนวนน้อย , มีข้อจำกัดเรื่องชนิดกระดาษ และความหนา

# Packing การแพ๊ค :

- Kraft wrap : การห่อส่งชิ้นงานด้วยกระดาษคราฟท์ จำกัดต่อห่อน้ำหนักไม่เกิน 5 kg.
- Paper band : การห่อส่งชิ้นงานด้วยสายรัดกระดาษ
- Carton : แพ๊คชิ้นงานลงกล่องลูกฟูก น้ำหนักบรรจุไม่ควรเกิน 15 kg. ส่งผลต่อการเสียรูป
- Pallet : การเตรียมชิ้นงานลง Pallet เพื่อเตรียมส่ง มักทำคู่กับ Kraft wrap , Carton เสมอ

# Delivery การจัดส่ง :

- กรณีส่งในประเทศ : ระบุสถานที่ส่งเพื่อคำนวณค่าส่งจากน้ำหนักชิ้นงานทั้งหมดที่ต้องส่งในแต่รอบส่ง(รวมน้ำหนักของการ packing เช่น carton , pallet ด้วย) โดยจะมีเรทที่แตกต่างกันไปขึ้นอยู่กับสถานที่ / น้ำหนัก / จำนวนรอบ
- น้ำหนักส่งผลต่อจำนวนรอบส่ง และเรทส่ง ข้อมูลสามารถใช้จาก database ได้
- กรณีส่งต่างประเทศ : จะต้องจัดวางบน Pallet และโหลดขึ้นตู้คอนเทนเนอร์ โดยจะมีการคำนวณเรทส่งแบบ FOB ปัจจุบันงานส่ง Packaging ยังไม่มีบริการส่งต่างประเทศ
