[Z] Relations / Dependencies (เงื่อนไขเชื่อมโยง)

1. Print Type -> Special Ink
   1.1 ถ้าเลือก Jet Press / Flexo / Konica => ไม่มีสีพิเศษ , ปิดการใช้สีพิเศษทั้งหมด ([L] ไม่แสดง/ไม่ให้เลือก)
   1.2 ถ้าเลือก Offset => ใช้สีพิเศษได้

2. Print Type -> Component Type
   2.1 Offset => เลือก Component Type ได้ 1 / 2 / 3
   2.2 Flexo => เลือกได้เฉพาะ Component Type 3
   2.3 Jet Press => เลือกได้เฉพาะ Component Type 1 / 2
   2.4 Konica => เลือกได้เฉพาะ Component Type 1

3. Print Type -> ข้อจำกัดแกรมกระดาษ
   3.1 Jet Press => 190–500 gsm
   3.2 Konica => 60–350 gsm
   3.3 Offset / Flexo => ตาม master data

4. Component Type -> ข้อมูลที่ต้องกรอก
   4.1 Type 1 (ไม่ประกบลูกฟูก) => ต้องกรอก [H] กระดาษ, ไม่ต้องกรอก [I] ลูกฟูก
   4.2 Type 2 (ประกบลูกฟูก) => ต้องกรอก [H] + [I], สีด้านใน = 0 อัตโนมัติ
   4.3 Type 3 (เฉพาะลูกฟูก) => ต้องกรอก [I] เท่านั้น, สีด้านใน = 0 อัตโนมัติ

5. Corrugated Custom -> Manual Layout
   5.1 ถ้า Component Type = 2 และเลือก “ราคา/แผ่น” ในลูกฟูก Custom => ต้องเลือก Manual Layout [S]

6. Coating Drip‑Off -> Special Ink Drip off
   6.1 ถ้าเลือก Coating UV-D (Drip-Off) => ระบบเพิ่ม Special Ink “Drip off” หมึก UV + พิมพ์ลายเส้น (stripe) และล็อกให้ใช้เสมอ
   6.2 ถ้า Print Type ไม่รองรับสีพิเศษ (Jet Press / Flexo / Konica) => ไม่ควรเลือก UV-D

7. Coating -> เงื่อนไขข้อมูลพิเศษ
   7.1 S-UV / S-UV-S => ต้องระบุขนาดเคลือบ (กว้าง x ยาว)
   7.2 B-PACK => ต้องระบุชนิดพลาสติก (PVC / PET)
   7.3 P-PAT => ต้องระบุหมายเลข Pattern
   7.4 S-WTB / UV_GAP / UV_ANTI_GAP / S-WTB-HR / S-H-WTB / S-UV-ANTI => ระบบเพิ่ม Material Process “ผ้ายาง … เว้นลิ้น”

8. Konica + PP Sticker Paper -> OPP Cold Film
   8.1 ถ้า Print Type = Konica และ Paper Code เป็น PP-CKT / PP-GKT / PP-MKT => เปิดให้เลือก Coating OPPC-1 / OPPC-2
   8.2 ถ้าไม่เข้าเงื่อนไข => OPPC-1 / OPPC-2 ถูกตัดออกจากตัวเลือก

9. Reprint Plate (เฉพาะ Offset)
   10.1 ถ้า Print Type = Offset และเลือก Reprint => แสดงตัวเลือก “ใช้ Plate เก่า”
   10.2 ถ้าไม่ใช่ Offset => ซ่อน/ปิดตัวเลือกนี้

10. Ink Type / จำนวนสี
    11.1 ถ้า Print Type = Flexo => จำนวนสีต่อด้านพิมพ์ไม่เกิน 2 สี
    11.2 ถ้า Print Type = Offset และ Ink Type = UV => จำนวนสีต่อด้านพิมพ์ไม่เกิน 6 สี

11. ลิมิตสี
    12.1 ถ้าเลือก “ลิมิตสี” => ต้องระบุจำนวนเล่มลิมิตสี

12. Konica-only Options
    14.1 Print Type = Konica => เปิด Black Printing (ถ้าไม่ใช่ Konica จะถูกปิด)
    14.2 Print Type = Konica => เปิด Digital Die‑cut (ถ้าไม่ใช่ Konica จะถูกปิด)
