  เงื่อนไขเพิ่มเติม :
  - ใบพิมพ์ควรมากกว่า 1,000 เพราะจะต้องใช้ใบพิมพ์เพื่อตั้งเครื่อง 300-400 ใบพิมพ์เสมอ (ไม่เหมาะกับงานใบพิมพ์น้อยกว่า 1,000)
  - ถ้าเป็นงาน ไม่ประกบลูกฟูก จะต้องวาง Layout ให้ขนาดไม่เกิน 29.5\*41.75"(ตามขนาดของเครื่องไดคัท)
  - ใบพิมพ์ > 5,000 ใบพิมพ์ และพิมพ์สีไม่เกิน 4 สี ให้ลง Cut 2 ก่อนเสมอ
  - ใบพิมพ์ > 1,000 ใบพิมพ์ และพิมพ์สี > 6 สี ให้ลง Cut 1 ก่อนเสมอ
  - ใบพิมพ์ < 1,000 ใบพิมพ์ ใน Cut 1 ให้เปลี่ยนขนาดกระดาษใหม่ เพื่อให้ได้ใบพิมพ์เยอะขึ้น (ต้องมากกว่า 1,000)
  - งานประกบลูกฟูก / ไม่ประกบลูกฟูก + UV ขนาดกระดาษจะต้องไม่เกิน 30.9\*43.3" (ขนาดเครื่องเคลือบ UV)

### ระบบพิมพ์ Jet press

    Min. Paper Size :
    - width : 15.50"
    - length : 21.50"

    Max. Paper Size :
    - width: 23.03"
    - length: 29.52"

    ความกว้างหน้าม้วนกระดาษ :
    - min: 15.50"
    - max: 23.03"

    ความกว้างด้าน cut off :
    - min : 21.50"
    - max : 29.52"

    Print Color :
    - min : 0
    - max : 8

    Component Type :
    - ไม่ประกบลูกฟูก
    - ประกบลูกฟูก

    ความหนากระดาษ (gram) :
    - min : 250
    - max : 600

    Special Ink :
    - NO

    เงื่อนไขเพิ่มเติม :
    - หาก Offset ใบพิมพ์น้อยกว่า 1,000 ให้ใช้ Jet Press
    - หาก Offset ใบพิมพ์น้อยกว่า 1,000 และมีสีพิเศษ ให้พิจารณาใช้ Jet Press (ต้องคุยกับลูกค้าเรื่องสีร่วมด้วย แต่ให้ยึด Jet Press เป็นหลัก)
    - หาก Offset ใบพิมพ์น้อยกว่า 5,000 ใบพิมพ์ และลูกค้าต้องการสีตรงให้พิจารณาใช้ Jet Press ก่อน
    - หากวาง Layout ด้วย 4 size กระดาษ Standard ของ Jet Press แล้วต้นทุนถูกกว่า Offset ให้ใช้ Jet Press
    - ไม่เหมาะกับงานสีพิเศษ เพราะใช้เครื่องผสมเองให้ได้สีเฉดเดียวกัน(อาจไม่ตรง)
    - หากมีเคลือบ UV จะต้องใช้ UV Tapetest เพื่อให้เคลือบติด
