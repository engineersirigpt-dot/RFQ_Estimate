7.5 กฎสกัดสำคัญ (AI) — กันการเดา (hallucination)

  • paper_type / paper_gram : เติมเฉพาะเมื่อมีคำตรงตัว (อาร์ตการ์ด/Ivory/Kraft/Duplex/แกรม/gsm) — ห้ามเดาจากชนิดสินค้าหรือรหัส CAD เช่น "DP350"
  • corrugated : ตั้ง type=2/3 เฉพาะเมื่อมี keyword ลูกฟูก ; label ว่าง "Flute:" ไม่นับเป็นหลักฐาน
  • box_template_id : หลักฐานหลัก = รูป dieline ที่อัปโหลด ; Template 12 (Custom) เฉพาะเมื่อไม่มี template ตรง
  • colors : นับเผื่อ CMYK=4, +white base +1, +metallic/special +1 ; "CMYK + ทนแดด" → +2 (special_inks M,Y)
  • ink_type vs coating : UV ink = หมึกพิมพ์ ("พิมพ์ UV") ; UV coating (Spot UV/Drip off) = เคลือบ ≠ ink_type
  • quantities / deliveries : เติมเฉพาะเมื่อมีตัวเลข/ชื่อจังหวัดไทยจริง ; label ฟอร์มเปล่าไม่นับ
  • is_multiple_f : true เมื่อหลาย design code สเปกเดียวกัน → ใช้ f_codes[] แทน quantities[]
