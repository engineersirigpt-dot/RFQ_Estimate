# งานให้ GPT: ตีเฉลยทรงกล่องจากไดไลน์ (blind labeling — first pass สำหรับ gold set)

> **บริบท:** เรากำลังสร้าง "gold set" (ชุดเฉลยที่เชื่อถือได้) เพื่อวัดความแม่นของระบบ AI จับทรงกล่องจากไดไลน์ วิธี: **GPT ตีก่อน (คุณ) → Claude ตรวจซ้ำ → จุดที่ 2 AI ขัดกัน = ให้คนตัดสิน** คุณจะเห็นแต่รูป (ไม่เห็นเฉลย) เพื่อความยุติธรรม

## งานของคุณ
ผมจะแนบ **ไดไลน์หลายรูป (เลข #1 เป็นต้นไป ตามลำดับที่แนบ)** — จำแนกแต่ละรูปเป็น **box_template 1 ใน 12 แบบ** พร้อมเหตุผล

## 12 ทรงมาตรฐาน
| # | ชื่อ | ลักษณะเด่น |
|---|---|---|
| 1 | Reverse Tuck End | ฝาบน-ล่างเสียบ **คนละทาง** (ก้นเป็นฝาเสียบ ไม่ทากาว) |
| 2 | Straight Tuck End | ฝาบน-ล่างเสียบ **ทางเดียวกัน** |
| 3 | Snap Lock Bottom | ก้นล็อกแบบพับสน็อป (ไม่ทากาว, ไม่มีเส้นทแยง) |
| 4 | Tuck Top Auto Bottom | ฝาบนเสียบ + **ก้นเป็น auto-lock: มีเส้นพับทแยง (crash-lock) + ทากาวก้น** |
| 5 | Tray | ถาดเปิดบน (พับมุม 4 มุม) |
| 6 | Frame-Vue Tray | ถาดโชว์ มีกรอบใน |
| 7 | Bento (Tray+Lid) | ถาดมีฝาครอบติดกัน |
| 8 | Gable Top | มี **หูหิ้ว/ช่องจับ** ยอดแหลม |
| 9 | Sleeve | ปลอกสวม (สี่เหลี่ยม เปิด 2 ด้าน ไม่มีฝาบน-ล่าง) |
| 10 | Pillow Box | ทรงหมอน ปลายโค้ง |
| 11 | Seal End | ปิดปลายด้วยกาว (ฝาบน-ล่างไม่เท่ากัน) |
| **12** | **Custom** | **ไม่เข้าทรง 1-11** (ดูกฎ Custom ด้านล่าง) |

## กฎสำคัญ (จากประสบการณ์จริง)
1. **Custom (12) เมื่อมีฟีเจอร์พิเศษข้อใดข้อหนึ่ง:**
   - หน้าต่าง die-cut / ช่องเจาะโชว์สินค้า
   - ขอบโค้ง/หยัก/เว้า (scalloped/arched)
   - หูหิ้ว/รูแขวน (hang-tab)
   - ฝาครอบ/wrap เปล่า ไม่มีตัวปิดกล่องในตัว
   - กล่องลูกฟูก RSC (4 ผนัง + ฝาบน-ล่าง ไม่มีฝาเสียบ)
   - จำนวน body panel **มากกว่า 4** (นับตามเส้นพับแนวนอน)
2. **แยกตระกูล tuck (1 vs 2 vs 4) — ดูที่ "ก้น":**
   - ก้นเป็นฝาเสียบธรรมดา (สมมาตรกับฝาบน ไม่มีเส้นทแยง) → **1 หรือ 2**
   - ก้นมี **เส้นพับทแยง crash-lock + ทากาว** → **4**
   - 1 vs 2: ฝาบน-ล่างเสียบคนละทาง=1, ทางเดียวกัน=2
3. **LAY = การจัดเรียงหลายกล่องบนแผ่นเดียว (imposition)** — จำแนก **ทรงของกล่อง 1 ตัว** ไม่ใช่ "หลายกล่อง"
4. ถ้ามีตัวเลขขนาดกำกับ ใช้ช่วยได้ (เช่น panel widths บอกจำนวน panel)

## รูปแบบคำตอบ (ต่อรูป)
ตอบเป็นตารางหรือ JSON — ต่อรูป #N ให้:
```json
{ "num": 1, "template": 4, "template_name": "Auto Bottom",
  "reason": "ก้นมีเส้นพับทแยง crash-lock ชัดเจน + ทากาวก้น",
  "confidence": "high | medium | low",
  "uncertain": false }
```
**สำคัญ:**
- **เหตุผลต้องอ้างโครงสร้างจริงที่เห็น** (โดยเฉพาะ "ก้น" สำหรับ tuck) ไม่ใช่แค่เดา
- ถ้าไม่ชัด ให้ `confidence:"low"` + `uncertain:true` **อย่าเดามั่ว** — การบอกว่า "ไม่แน่ใจ" มีค่ากว่าเดาผิด
- ถ้าเป็น Custom ให้บอกว่า **ฟีเจอร์พิเศษอะไร**ทำให้เป็น Custom
